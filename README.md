# samboo

Expo-app byggd med Expo Router, NativeWind och React Native Reusables.

## Kom igång

Kräver Node 22+ (se `.nvmrc`, kör `nvm use`).

```bash
npm install
npx expo start
```

## Kommandon

```bash
npx expo start -c   # starta med rensad cache
npx expo start --web  # kör appen i webbläsaren (react-native-web)
npm run build:web   # statisk webbexport till dist/
npx expo lint       # lint
npx tsc --noEmit    # typkontroll
```
